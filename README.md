## Getting Started
1. Add .env file.
2. Create with a command or manually the database for the app.
3. Start the local server or connect to the database, do the necessary modifications in conectarDb.ts file.
4. Install [`turbo`](https://turborepo.com/docs/getting-started/installation)
5. Run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```
